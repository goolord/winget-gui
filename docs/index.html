winget-gui

A fast replacement for Windows’ Settings → Apps → Installed apps, built on WinGet’s COM API — with bulk and automated uninstallation.

Download for Windows

  • Fast. The list appears as soon as WinGet’s local catalog is read; upgrades fill in afterwards in the background. 1,337 apps listed in 1.7 s, against ~16.5 s for Settings.
  • Bulk operations. Check any number of apps and uninstall or upgrade them in one go, silently or interactively, with a live queue you can stop, skip, and retry.
  • Automation. Select apps by rule, save rule files, and run them headlessly with winget-gui-cli.
  • More detail than Settings. WinGet id, source, scope, installer type, architecture, install location, product codes, disk usage per drive, and available upgrades.

Unzip anywhere and run winget-gui.exe. Requires Windows with App Installer (WinGet) present; the folder is self-contained. Source and build instructions are on GitHub.
